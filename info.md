### Основные компоненты:
* **Frontend (Next.js):** SPA/SSR приложение на App Router, оптимизированное для работы с медиа-контентом, поддерживающее real-time уведомления через WebSockets.
* **Backend Gateway (Go):** Высокопроизводительный сервис на Clean Architecture. Отвечает за аутентификацию, валидацию, координацию распределенных транзакций и маршрутизацию запросов к БД и ML-сервису через REST API.
* **ML Worker (Python / FastAPI):** Изолированный сервис для инференса ML-моделей (например, CLIP / ViT), трансформирующий графические данные в n-мерные вектора. Предоставляет REST API для синхронных операций.
* **Брокер сообщений (Redis Streams / RabbitMQ):** Асинхронный пайплайн для обработки тяжелых задач (генерация векторов) без блокировки клиентских HTTP-сессий.
* **Хранилище данных:**
    * `PostgreSQL` — реляционные данные, профили, метаданные изображений.
    * `Qdrant / pgvector` — специализированная база данных для быстрого поиска по сходству векторов (KNN-поиск).
    * `Redis` — кэширование, сессии, лимитирование запросов (Rate Limiting) и брокер очередей.
